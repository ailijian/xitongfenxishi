# 阶段 D：PWA、备份恢复与交付质量

已实现manifest、192/512图标与maskable图标、完整核心资源预缓存、SPA离线导航、安装提示、离线状态和版本更新提示。开发服务不启用Service Worker，离线验收使用生产构建。全部记录在IndexedDB；浏览器持久存储申请和全量JSON备份均可用。

全量备份覆盖12类用户数据。恢复先校验、预览，二次确认后以一个数据库事务整体替换。损坏/未知ID/未来schema/异常当前版本评分会拒绝；写入中途失败会回滚。历史尝试携带内容版本，资料更新后不重判旧成绩；未标记或较早版本的历史原判分保留。重置需二次确认。

修复并验证了刷新前会话尚未创建时点击丢失的竞争窗口。模考收藏与单题接口都在整卷交卷前拒绝判分，整卷提交/尝试/错题更新在同一事务中完成，避免通过其他入口提前获得答案。原始时间戳保留，提交序号处理同毫秒和设备时钟变动。

主要文件：`src/storage/backup.ts`、`src/components/BackupPanel.tsx`、`PWAStatus.tsx`、`StorageBoundary.tsx`、`vite.config.ts`、`public/`、生产测试配置与静态托管配置。
