# 阶段 C：案例、论文与完整模考

已交付9套完整案例的独立作答、答案揭示、原文采分组勾选、漏分项、25分自评和多次训练历史。案例分问可独立收起，参考答案只能在三问有独立作答后揭示。

10个论文专题接入共享真实项目素材库、提纲与正文编辑、字数、自查、复制、TXT/Markdown导出和刷新续写。不生成经历，不做官方自动评分。模考论文保留提交快照，后续草稿修改不覆盖已完成模考。

整卷模拟使用独立75题，题号导航、退出继续、收藏与可选150分钟参考倒计时。整卷交卷前不显示答案、解析或成绩；未答题计0分而不伪造作答记录。完整训练按75单选→任选3案例→1论文进行，选择成绩、案例自评和论文状态分开展示。

数据库v2增加案例草稿/尝试、论文、项目素材及模考记录，v1升级保留既有进度。

主要文件：`src/domain/training.ts`、`src/storage/training.ts`、`src/pages/TrainingPages.tsx`、`src/pages/MockPage.tsx`、进度页。

实际验证：C核心39/39单元测试通过（含原文采分、整卷隔离、论文快照、数据库升级）；整合后43/43单元测试通过。`npm run test:e2e` 11/11通过，含375px逐题作答全部75题，再完成三案例与论文的完整流程。生产构建通过。

论文“完成”由本人逐项自查并确认，系统不判断技术内容质量，也不把短草稿的字数当作正式达标证明。正式考试批次、时长与字数以当次题目/准考证为准。所有备考内容仍保留原创模拟标签。
