# 学习内容和发布验收说明

## 说明
- 15课 / 30道全新原创理解练习（不计入既有150题，不进入模考池）。
- 课程围绕同一个「社区医院预约系统」情境。所有数字阈值均为教学示例，不代表实际医院合同或软考官方题目。
- 原始 `K001`—`K014`、`K075` ID 一一映射；与现有 `K004/K005/K010/K011` 自评状态保持分离。
- 当前供集成审核，**没有修改用户仓库、没有部署 staging**。

## 需要学会的三件事
1. 能用自己的话讲出术语，而不是背一串英文缩写。
2. 能把术语放进预约业务案例，指出“为何采用、适用边界、容易混淆处”。
3. 能解释错误选项具体为什么错，独立完成一段简短的设计或判断。

## 课程验收
- 每课 1 句人话总结、1 个业务场景、至少 3 个讲解步骤、至少 4 个示范分析步骤、2 道4选1题（四个选项各有解析）、2 个闭卷自述问题。
- 对 K006—K011 重点检查 UML/DFD 术语及图类型不混淆。
- K013 瀑布/原型/增量/敏捷是在典型适用性上比较，并非排他绝对。
- K014 Scrum 标准职责和 Review/Retrospective 语义正确。
- K075 与 K012 可串联，但不误认为“数字化自动化=BPR”。
