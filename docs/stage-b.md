# 阶段 B：知识掌握驱动的可学习 MVP

已交付首页动态任务、知识检索、76张知识卡闭卷回忆、自检与可信关联题验收、24小时巩固状态机、章节75题、错题/收藏、刷新续学与IndexedDB持久化。阅读不会通关，所有尝试与原始时间戳保留；错题排序采用独立提交序号，避免时间相同或设备时钟变化错配最新结果。

任务按原文15/15/15/15/16分配。到期复习优先，历史未过关任务自动顺延，超前通过减少后续任务，D6/D7欠账明确显示。启动日和单卡任务日期可修改，保留全部记录。

主要文件：`src/domain/study.ts`、`src/storage/db.ts`、`src/pages/StudyPages.tsx`、`src/pages/ProgressPage.tsx`。

实际验证：`npm run test` 32/32通过；`npm run test:e2e` 9/9通过（含375px首轮→24小时复测、错题二刷、刷新未交答案与自评卡）；320/375/390/430px共28个页面检查无整页横向滚动。

Playwright严格冻结初次提交时间，以测试完整24小时边界；真实时间戳差不足24小时不会巩固。单元测试另外覆盖24小时前后边界、跨月/跨年、复测失败、A/B复习间隔与日期重排。

本阶段暂不包括整卷模考、案例编辑、论文草稿、PWA和备份，后续阶段继续交付。实际手机安装与系统回收后的恢复仍需真机验收，浏览器仿真不能代替真机。
