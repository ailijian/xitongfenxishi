## 目标

## 优先级和步骤

1. 阅读 `README_FIRST.md`、`CONTENT_QA_REPORT.md`，核对已上线 D1 的 `src/data/lessons/day1_beginner_lessons.json` 及课程页面组件的真实schema；把 `day2_day5_beginner_lessons.json` 作为独立静态资料放入 `src/data/lessons/`（可按D2-D5拆分以便分块加载）。**不要使用全量校对文件再次导入D1，不能更改旧ID。**
2. 沿用 K001 已获用户认可的零基础课程UI：先讲人话与场景→渐进步骤→带做例题→概念图→原创理解题（答案门禁）→闭卷复述→折叠速记。四组不同章节仅补充必要交互，例如SQL代码块换行、计算题演算步骤与图表横向滚动。
3. 选择题调用现有教学题组件，交卷前隐藏正确答案和所有optionExplanations；支持错后逐项分析和重做。绝不把这122题与原RK001–RK150混池或计入客观掌握；仍然只在经过审核的独立客观题证据下提升客观验证。
4. `case_paper_beginner_coaching.json` 提供两种新辅导视图：案例“不会做？先看拆题思路”，以及论文“写作教练”。案例的`answerPointExamples`应在学生先提交草稿或主动确认查看参考答案后显示，防止污染自评；原案例题干、分数、rubric、历史草稿原封不动。论文先提示真实项目证据，不得自动写入虚构项目。辅导不自动给分。
5. 可选的教学增强：K037显示supplement.copyableSql并保留原字符；K069/070/071/063使用“每步显示”逐步演算；图示包括流程图及sequenceDiagram，在离线PWA也能正确显示。
6. 不要进行knowledge-v2的数据库schema迁移，也不要批准261项待审checkpoint；本轮只加静态课程和独立辅导，不改IndexedDB用户数据结构。新增课程可独立撤回而不影响原资料。

- 数据完整性：61课程ID唯一/来自76原卡；122新题ID唯一；题目A/B/C/D完整、只有一个键入答案；全部正确答案与选项解析同步重排，不能出现解析错位。
